## 伦敦的线路：电信双程 CN2，移动回程是 CMIN2

先把伦敦的实际走向摆出来：

- 电信：去程和回程都走 CN2
- 联通：回程强制走 CN2
- 移动：回程已优化为 **CMIN2**
- 延迟：第三方测评记录约 200ms
- 下载速度：第三方测评记录最高约 60Mbps

这套配置叫“CN2 为主、移动走 CMIN2”，和圣何塞那种“三网回程全部强制 CN2 GIA”不是一回事。CN2 GIA 是电信的高优先级承载网，晚高峰拥塞少；CMIN2 是中国移动的同类产品，对移动宽带用户友好，但它不走电信那条线。所以如果你用的是移动宽带，伦敦的回程走 CMIN2，体验未必比走 GIA 差，但也不能简单等同于“三网 GIA”。

### 和圣何塞差在哪

圣何塞离国内最近，延迟约 168ms，比伦敦低 30ms 左右。电信去程走 59.43 段 CN2 GIA，回程三网全部强制 GIA，配置比伦敦更整齐。如果你搭的是面向国内用户的后台、博客、中转，这 30ms 的差距在打开后台、保存文章这类操作上是能感觉到的。

伦敦的价值在于 IP 归属地。做英国本地化业务、需要英国 IP 注册或验证、想把节点分散到欧洲，这些场景圣何塞替代不了。延迟 200ms 对网页访问来说不算优秀，但也在可用范围。

法兰克福在两者之间，180ms 左右，还多了移动 CMIN2 的加成和流媒体解锁的口碑。如果你的业务面向欧洲大陆而不是英国，法兰克福比伦敦更合适。
